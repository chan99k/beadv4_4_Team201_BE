DB 서비스 가드 L2, @EventIdempotent L3)이 의도대로 동작한 것을 실측으로 확인했다.

## 재현 절차

이 실행에 도달하기까지 막힌 지점이 셋 있었다. 다음 사람이 같은 데서 막히지 않도록 적는다.

### 1. Gradle 이 JDK 25 에서 죽는다

```
java.lang.IllegalArgumentException: 25.0.2
  at org.jetbrains.kotlin...JavaVersion.parse(JavaVersion.java:307)
  at ...JavaVersionUtilsKt.isAtLeastJava9
```

Gradle 이 쓰는 번들 Kotlin 컴파일러가 "25.0.2" 라는 버전 문자열을 파싱하지 못한다.
**Gradle 자체는 JDK 21 로 돌리고 컴파일만 toolchain 25 에 맡긴다.**

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew :bootstrap:api-server:bootJar -x test
```

앱 실행은 JDK 25 로 한다. 빌드 도구의 제약이지 런타임 제약이 아니다.

### 2. dev 프로파일만으로는 시드가 안 들어간다

부하테스트용 시드는 `R__seed.sql` 8개 파일 안에서
`IF '${is_staging}' = 'true' THEN` 으로 묶여 있다. dev 프로파일은 이 값이 `false` 라
members/fundings/wishlist_items 가 0건이다. `application-loadtest.yml` 이 이 값을
`true` 로 덮으므로 **loadtest 프로파일을 같이 올려야 한다.**

```bash
--spring.profiles.active=dev,loadtest
```

기동 로그에 `=== LoadTest SecurityFilterChain ACTIVE ===` 가 뜨면 적용된 것이다.

### 3. Kafka 가 원격을 가리킨다

`.env` 의 `KAFKA_BOOTSTRAP_SERVERS` 가 외부 클러스터라, 로컬 검증에서는 명시적으로
로컬 redpanda 로 덮었다.

```bash
--spring.kafka.bootstrap-servers=localhost:9092
```

### 전체 절차

```bash
cd giftify-be

# 1) 인프라
docker compose up -d postgres redis elasticsearch redpanda
#    4개가 healthy 가 될 때까지 대기

# 2) 빌드 (Gradle 은 21, 컴파일은 toolchain 25)
JAVA_HOME=$(/usr/libexec/java_home -v 21) \
  ./gradlew :bootstrap:api-server:bootJar -x test

# 3) 기동 (앱은 25)
set -a; . ./.env; set +a
JAVA_HOME=$(/usr/libexec/java_home -v 25.0.2) \
  "$JAVA_HOME/bin/java" -jar bootstrap/api-server/build/libs/api-server-1.0.0-SNAPSHOT.jar \
    --spring.profiles.active=dev,loadtest \
    --spring.kafka.bootstrap-servers=localhost:9092

# 4) 시드 확인 (0 이면 loadtest 프로파일이 안 붙은 것)
#    members 1001,1051 = 2 / fundings 1001 = 1 / wishlist_items 1001 = 1

# 5) k6
cd infra/monitoring/k6
k6 run --env BASE_URL=http://localhost:8080 --env MOCK_AUTH=true \
       --env TEST_FUNDING_ID=1001 --env TEST_WISHLIST_ITEM_ID=1001 \
       --env TEST_RECEIVER_ID=1051 --env TEST_PRODUCT_ID=11 \
       --summary-export=results/idempotency-$(date +%Y%m%d-%H%M%S).json \
       scripts/idempotency-test.js

# 6) DB 확인 - buyer_id=1001 주문이 정확히 1건이어야 한다
```
